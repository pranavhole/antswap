# 🦄 Ant-Swap — Decentralized Exchange (Concept Prototype)

> ⚠️ **Note:** This project is currently inactive and was originally developed as a learning prototype for decentralized exchanges (DEX).  
> It was an experimental implementation focused on understanding the core architecture of AMM-based swaps, liquidity pools, and Web3 integrations.  
> The repository remains public for reference and educational purposes.

---

## 🚀 About the Project
Ant-Swap was a proof-of-concept **Decentralized Exchange (DEX)** designed to simulate token swaps, liquidity provisioning, and on-chain transaction handling using smart contracts.

### ✳️ Features (Implemented in the Prototype)
- Basic ERC-20 token swap logic written in **Solidity**
- Liquidity pool structure using **constant product market maker (CPMM)** logic
- Wallet connection via **MetaMask** using **Ether.js**
- Basic frontend with **Next.js** and **Web3.js** integration
- **Hardhat** scripts for contract compilation, deployment, and local testing

---

## 🧠 Learning Outcomes
While the project is no longer maintained, it provided valuable hands-on experience with:
- Smart contract design and gas optimization
- Interacting with Ethereum nodes using Web3.js
- Managing liquidity and transaction states
- Building decentralized UI using React + Next.js
- Integrating blockchain logic with frontend components

- **Backend / Smart Contracts:** Solidity, Hardhat, Ether.js
